# 실험 기록
> 열었을 때, 어디까지 했는지를 확인하는 부분
상태: 완료

## 질문과 가설
> 예상을 먼저 적고, 실제 실험 후 예상과 맞았는지를 확인
> 예/아니오로 답할 수 있는 질문, 수치적으로 표현할 수 있는 변화 중심을 적기
- 해결할 문제: 같은 데이터와 학습 조건에서 CNN이 MLP보다 손글씨 숫자를 더 잘 분류하는가?
- 예상하는 변화와 이유: CNN의 Test 정확도가 5% 이상 높을 것. Convolution은 이웃 픽셀들을 묶어서 연산해 모양이 비슷하면 위치가 조금 달라도 인식하지만, MLP는 모든 픽셀을 다 따로 본다.
- 변경하는 변수 하나: 모델 구조

## 통제 조건
> 변인 통제. 하나의 조건만 변경하고 나머지 조건은 유지하기
- 데이터 분할·샘플 수·seed: `train` 데이터셋에서 학습 8,000 / 검증 1,000, `test` 데이터셋에서 1,000개의 데이터 랜덤 추출. seed=42
- 모델·학습률·배치·입력 길이: Adam lr=1e-3, batch=64, input=28x28 고정. 파라미터 수: MLP 421,218 / CNN 409,034 (3% 차이)
- 학습 예산 (optimizer step / 환경 step): 375 step (3 epoch)
- 평가 데이터·평가 방식: 고정 test 1,000장에 대한 정확도. 두 모델 모두 같은 이미지 사용

## 결과
> 수치적인 결과. 결과 수치가 얼마나 흔들릴 수 있는지 (=신뢰구간), 비용을 모두 정리
> `scipy.binomtest(정답 수, n).proportion_ci(method="wilson")`

| 실행 | 변경 | 주요 지표 | 평가 n | 95% CI | 시간 | 최대 GPU 메모리 |
|---|---|---|---|---|---|---|
| 기준선 | MLP | Test Acc = 0.927 | 1,000 | [0.909, 0.942] | - | - |
| 비교 | MLP->CNN | Test Acc = 0.964 | 1,000 | [0.951, 0.974] | - | - |

정답률의 95% 신뢰구간은 Wilson 구간으로, 다른 지표는 bootstrap으로 구합니다.

두 모델을 비교할 때는 같은 평가 사례로 paired bootstrap을 돌려 점수 차이(비교 − 기준선)의 95% 신뢰구간을 구합니다. 이 구간 전체가 비교 모델이 더 좋은 쪽에 있을 때만 개선이라고 씁니다.

- 차이 (CNN-MLP): +0.037, 95% CI [+0.022, +0.053] (test 1,000장, paired bootstrap 10,000회)
- 신뢰구간 전체가 0보다 크기 때문에, MLP에서 CNN의 변화는 개선으로 판정

## 판단
> 결과 및 실패를 기반으로, 이를 개선할 수 있는 다음 행동 하나를 적기.
- 가설을 지지하는 관찰: 두 모델의 파라미터 차이가 적고, 다른 조건이 동일한 상태에서 MLP에 비해 3.7%p의 상승을 보였다.
- 가설과 다른 관찰: 예상은 5%p 정도였지만 실제로는 3~4%p 개선되었다. "위치가 달라도 인식한다"는 이번 실험에서 검증되지 않았다.
- 다음 행동 하나: train 데이터셋에 augmentation을 거쳐 일반화 성능을 개선하는 시도를 할 수 있다.

완료: 기준선 + 변경 하나 + 동일 평가 + 결과 해석. 성능 개선은 필수 조건이 아닙니다.
